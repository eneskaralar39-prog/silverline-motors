# Silverline Motors

Bağımsız, Mercedes-Benz modellerini bilgi amaçlı tanıtan, özgün tasarımlı statik otomobil portföy sitesi.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın. Harici paket veya API gerekmez.

## GitHub Pages
1. GitHub'da herkese açık yeni bir repository oluşturun.
2. `index.html` dosyasını repository köküne yükleyin.
3. Settings > Pages > Build and deployment > Deploy from a branch seçin.
4. `main` dalı ve `/(root)` klasörünü seçip kaydedin.

## Lisans ve marka notu
Sitenin kaynak kodu MIT lisanslıdır. Mercedes-Benz adı yalnızca marka/modelleri tanımlamak için kullanılmıştır. Bu site resmi değildir ve marka ile bağlantılı değildir. Üçüncü taraf markalar MIT lisansının kapsamında değildir.

Kartlardaki araç çizimleri orijinal, basitleştirilmiş SVG silüetlerdir. Harici fotoğraf, logo, font veya ikon kütüphanesi kullanılmaz.
